# Equity

Нативное Android-приложение для ведения личного бюджета, учета доходов и расходов, анализа финансовых тенденций и планирования накоплений.

## Стек технологий

- Язык: Kotlin 2.0
- Пользовательский интерфейс: Jetpack Compose (Material 3 Expressive, плоский дизайн без теней)
- Архитектура: Clean Architecture + MVVM (ViewModel, StateFlow, Coroutines)
- Локальная база данных: Room Database 2.6
- Фоновые задачи: AndroidX WorkManager (периодическая обработка автодобавлений)
- Настройки: SharedPreferences + StateFlow
- Виджет рабочего стола: AppWidgetProvider (RemoteViews)
- Сеть: встроенный HTTP-клиент для парсинга актуальных курсов валют (ЦБ РФ / Exchange Rates API)
- Целевая платформа: Android 14+ (minSdk 26, targetSdk 35, compileSdk 35)

## Функциональность

- Учет доходов и расходов с разделением по категориям, валютам (RUB, USD, EUR) и периодам (день, неделя, месяц, год, все время).
- Быстрые шаблоны описаний для каждой категории без необходимости повторного ввода вручную.
- Регулярные платежи (автодобавление): настройка автоматического начисления доходов (например, зарплаты) или списания расходов по расписанию (число месяца, дни недели, двухнедельный цикл).
- Парсинг курсов валют в реальном времени с поддержкой автоматической конвертации всех сумм и баланса в выбранную основную валюту.
- Расчет безопасного дневного лимита трат исходя из текущего баланса и заданной цели накоплений.
- Разнообразные графики и аналитика:
  - Сравнение доходов и расходов по временным интервалам.
  - Кумулятивная кривая динамики баланса.
  - Распределение трат по дням недели.
  - Круговая диаграмма долей расходов по категориям.
- Темы оформления: Системная, Светлая, Темная, AMOLED Black (абсолютный черный #000000).
- Поддержка динамических цветов системы (Material You) и тематической адаптивной иконки.
- Переключение языка интерфейса (Русский / Английский).
- Виджет для рабочего стола Android с балансом и расходами за месяц.

## Сборка и запуск

Сборка отладочного APK:
```bash
./gradlew assembleDebug
```

Установка на подключенное устройство через ADB:
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
